# 📓 Obsidian Vault（メモ & タスク管理）

このフォルダ **`vault/`** が Obsidian の保管庫（Vault）です。
GitHub 経由で **会社PC・自宅PC・スマホ**から同じメモ／タスクを同期して使います。

> 👉 **はじめて開く人は [`SETUP.md`](SETUP.md) の手順どおりに設定してください。**
> Obsidian で開くのは「リポジトリのルート」ではなく **この `vault/` フォルダ**です。

## フォルダ構成

| フォルダ | 用途 |
|---|---|
| `00_Inbox/`     | とりあえずの書き殴り・後で仕分けするメモ（新規ノートの既定の保存先） |
| `10_Daily/`     | デイリーノート（日付ごと。カレンダーから開く） |
| `20_Notes/`     | ちゃんと残す知識・調べ物・ナレッジ |
| `30_Tasks/`     | タスク管理ダッシュボード（[タスク管理](30_Tasks/タスク管理.md)） |
| `40_Projects/`  | 案件・プロジェクト単位のノート |
| `90_Templates/` | テンプレート（デイリー / タスク / 会議） |
| `99_Attachments/` | 画像など添付ファイルの置き場 |

## 使い方の流れ

1. **思いついたら** → `00_Inbox` にメモ（モバイルでもサッと）
2. **毎日** → カレンダーで今日の日付をクリック → デイリーノートでタスク・予定・ふりかえり
3. **タスクは** どのノートでも `- [ ] 内容 📅 2026-07-01` のように書けば、
   [タスク管理ダッシュボード](30_Tasks/タスク管理.md) に自動で集まる
4. **大事な知識は** `20_Notes` に整理して `[[リンク]]` でつなぐ

## 同期の仕組み（重要）

- 保存すると **Obsidian Git プラグイン**が自動で commit → push します
- 別の端末では起動時に自動で pull され、最新が落ちてきます
- ⚠️ **使い始めと使い終わりに少し待つ**（push/pull の完了）を習慣にすると競合が起きにくいです

詳細・各端末の設定・祝日カレンダー連携は [`SETUP.md`](SETUP.md) を参照。
