# 📓 Obsidian Vault（メモ & タスク管理）

**このフォルダがそのまま Obsidian の保管庫（Vault）です。**
これ専用の GitHub リポジトリに置き、**会社PC・自宅PC・スマホ**から同期して使います。

> 👉 **はじめての人は [`SETUP.md`](SETUP.md) の手順どおりに。**
> Obsidian で開くのは **このフォルダ（＝リポジトリのルート）** です。

## フォルダ構成

| フォルダ | 用途 |
|---|---|
| `00_Inbox/`     | とりあえずの書き殴り（新規ノートの既定の保存先） |
| `10_Daily/`     | デイリーノート（カレンダーから開く） |
| `20_Notes/`     | ちゃんと残す知識・調べ物 |
| `30_Tasks/`     | タスク管理ダッシュボード（[タスク管理](30_Tasks/タスク管理.md)） |
| `40_Projects/`  | 案件・プロジェクト単位 |
| `90_Templates/` | テンプレート（デイリー / タスク / 会議） |
| `99_Attachments/` | 画像など添付ファイル |

## 使い方の流れ

1. **思いついたら** → `00_Inbox` にメモ（スマホでもサッと）
2. **毎日** → カレンダーで今日をクリック → デイリーノートで予定・タスク・ふりかえり
3. **タスクは** どのノートでも `- [ ] 内容 📅 2026-07-01` と書けば
   [タスク管理ダッシュボード](30_Tasks/タスク管理.md) に自動で集まる
4. **大事な知識は** `20_Notes` に整理して `[[リンク]]` でつなぐ

## 同期の仕組み

- 保存すると **Obsidian Git プラグイン**が自動で commit → push
- 別端末では起動時に自動 pull で最新が落ちる
- ⚠️ 使い始め／終わりに少し待つ（同期完了）と競合しにくい

詳細・各端末の設定・祝日カレンダー連携は [`SETUP.md`](SETUP.md) を参照。
