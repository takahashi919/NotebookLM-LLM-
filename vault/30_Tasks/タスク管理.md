# ✅ タスク管理ダッシュボード

> Vault 全体のチェックボックス `- [ ] ...` を **Tasks プラグイン**が自動で集計します。
> このノートを開くだけで「期限切れ・今日・今後・未設定」が一覧になります。
> （要: コミュニティプラグイン **Tasks** を有効化）

## 🔥 期限切れ・今日まで
```tasks
not done
due before tomorrow
sort by due
```

## 📅 今後の予定
```tasks
not done
due after today
sort by due
```

## 📥 期限なし（いつかやる）
```tasks
not done
no due date
```

## ✔️ 最近完了したもの
```tasks
done
sort by done reverse
limit 20
```
